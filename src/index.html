Matriz de Desafios Cibernéticos

Selecione um desafio para acessar a aplicação vulnerável e iniciar o teste.

Reconnaissance
Fácil +50 pts

Reconhecimento & Vazamento de Código

Desenvolvedores frequentemente deixam arquivos de backup temporários (.bak) ou esquecem referências em robots.txt e comentários no código-fonte.

PENDENTE Explorar

• Dica 1: Verifique arquivos canônicos de rastreadores web como robots.txt na raiz do servidor.

• Dica 2: Procure por arquivos com extensão .bak ou comentários no HTML.

Nunca mantenha backups ou comentários sensíveis em pastas públicas do servidor web.

Injection
Fácil +100 pts

SQL Injection: Bypass de Autenticação

O portal de administração autentica usuários concatenando diretamente o login e senha na consulta SQL sem sanitização.

PENDENTE Explorar

• Dica 1: Tente quebrar a sintaxe com aspas simples: '

• Dica 2: Um payload clássico como ' OR 1=1 -- ignora a verificação de senha.

Utilize Prepared Statements (PDO com parâmetros vinculados como :user).

Client-Side
Médio +100 pts

Cross-Site Scripting (XSS)

O mural de recados da empresa salva e exibe os comentários dos usuários diretamente no navegador sem escapar tags HTML.

PENDENTE Explorar

• Dica 1: Teste se tags HTML como <b> ou <script> são renderizadas.

• Dica 2: Um payload simples como <script>alert(1)</script> demonstra o vetor.

Escape todas as saídas com htmlspecialchars($str, ENT_QUOTES, 'UTF-8').

Access Control
Médio +150 pts

IDOR: Controle de Acesso Quebrado

O perfil interno aceita um parâmetro numérico no endereço sem checar autorização de visualização de outros registros.

PENDENTE Explorar

• Dica 1: Altere o parâmetro user_id na URL.

• Dica 2: Consulte user_id=3 para ver o perfil do CEO.

Verifique permissões na sessão do usuário logado antes de retornar objetos por ID.

File Inclusion
Médio +150 pts

Local File Inclusion (LFI)

Um visualizador dinâmico de documentação carrega arquivos do sistema com base em ?doc= sem validar path traversal.

PENDENTE Explorar

• Dica 1: Suba níveis com ../ (ex: ../../secret_flag_system.txt).

• Dica 2: Tente ler arquivos do Linux como /etc/passwd.

Use whitelist restrita de arquivos permitidos e basename() para limpar o caminho.

Injection
Difícil +200 pts

Command Injection (RCE no Host)

A ferramenta interna de diagnóstico executa o comando ping concatenando diretamente o IP informado pelo operador.

PENDENTE Explorar

• Dica 1: No Linux, encadeie comandos no shell usando ; ou &&.

• Dica 2: Tente: 127.0.0.1; cat ../secret_flag_system.txt

Evite chamar comandos do SO diretamente; utilize escapeshellarg() e valide formato de IP.

Cryptography
Médio +150 pts

Adulteração de Cookies & Sessão

O cofre VIP valida o privilégio com base em um cookie auth_token codificado fracamente em Base64.

PENDENTE Explorar

• Dica 1: Inspecione o cookie auth_token no navegador (F12).

• Dica 2: Decodifique Base64, mude "role":"guest" para "role":"admin" e codifique de volta.

Utilize tokens assinados criptograficamente (JWT com HMAC) ou sessões no servidor.

Metodologia e Conceitos de Segurança

Compreenda o ciclo de exploração e correção das vulnerabilidades

1. Reconhecimento

Mapeamento de ativos, leitura de arquivos robots.txt, inspeção de código-fonte HTML/JS e detecção de arquivos de backup esquecidos em produção.

2. Injeções & Quebra de Lógica

Manipulação de comandos (Command Injection), queries SQL (SQLi) e renderização de scripts no navegador (XSS) através de entradas não sanitizadas do usuário.

3. Controle de Acesso & Sessão

Adulteração de identificadores de objeto (IDOR) e cookies fracos para obter privilégios administrativos sem possuir as credenciais devidas.
